# OCR-Document-Editor
Edit picture, screen capture or pdf document with offline OCR
install Python 3.12+ (or higher)

install ocr
Install Tesseract (the OCR engine). Download the Windows installer from https://github.com/UB-Mannheim/tesseract/wiki. During setup, under "Additional language data", tick Sinhala and Tamil, and keep the default install folder. 

build on Windows,download the "document_editor.zip" unzip and  run build_exe.bat. That produces dist\DocumentEditor\DocumentEditor.exe; build_exe.bat onefile produces a single dist\DocumentEditor.exe instead.
run ..\document_editor\dist\DocumentEditor\DocumentEditor.exe
